# 🏋️ Iron Obsidian Somatic Club — Premium Athletic Recovery Platform

## Full Stack Web Development – Task 3 (2026) | Future Interns

A high-performance, immersive, and conversion-focused business website engineered for **Iron Obsidian Somatic Club**, a premium athletic recovery, somatic wellness, and joint longevity center located in Khar West, Mumbai.

This project was developed as part of **Future Interns – Full Stack Web Development Task 3 (2026)** with the objective of designing, pitching, and monetizing a real-world local business through a modern web platform.

---

# 🚀 Project Overview

Iron Obsidian Somatic Club serves elite athletes, competitive powerlifters, bodybuilders, sports professionals, and fitness enthusiasts who require advanced recovery protocols, biomechanical optimization, mobility restoration, and performance enhancement services.

The website functions as a complete digital business platform that combines premium branding, intelligent client onboarding, appointment management, recovery analytics, and mobile-first conversion strategies.

Rather than operating as a traditional informational website, this platform acts as a modern lead-generation and client acquisition system.

---

# ⚙️ Local Development Setup

## Clone Repository

```bash
git clone git remote add origin https://github.com/Mpraveen89/FUTURE_FS_03.git
```

---

## Navigate to Project

```bash
cd iron-obsidian-somatic
```

---

## Install Dependencies

```bash
npm install
```

---

## Start Development Server

```bash
npm run dev
```

Application runs locally at:

```text
http://localhost:3001
```

---

# 🚀 Production Build

Generate optimized production assets:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```

Compiled assets will be available inside:

```bash
dist/
```
Run cmd :

```bash
npm install
```
